# Instructions

1) Utilisez le fichier parakeet-web-app pour commencer.
2) Le logiciel va s'occuper de vérifier si toutes le modèle Parakeet est présent.
    i) Si le modèle est absent, il vous proposera de le télécharger (600+ mo).
3) Un navigateur s'ouvrira avec l'interface de transcription ainsi qu'un terminal avec le serveur de transcription.
4) Pour fermer la transcription, vous devez fermer LE SERVEUR (terminal). La fenêtre n'est qu'un miroir de ce qui se passe sur le serveur.

# Ou trouver les transcriptions?

- Une fois les transcriptions commencées, elles sont automatiquement enregistrées dans le sous dossier "transcriptions" dans le dossier parakeet-web-app.
